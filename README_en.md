# Hearthstone Battlegrounds Power.log Analyzer (`bg_review.py`)

[日本語](README.md) | **English**

A Python script that parses Hearthstone Battlegrounds `Power.log` files and generates a visual **HTML review report** as well as a lightweight **Markdown log for AI analysis (`*_ai.md`)**.

It uses only the Python standard library, so no external packages are required.

---

## Key Features

- **Automatic Battlegrounds Extraction**: Automatically detects and parses only Battlegrounds matches (`GT_BATTLEGROUNDS*`) from a `Power.log` containing multiple games.
- **Turn-by-Turn & Reroll-by-Reroll Breakdown**:
  - Tavern minion/spell offerings for each reroll, frozen cards carried over from the previous turn, and cards purchased
  - Gold and maximum Gold before and after actions
  - Tavern Tier at the start and end of each turn, plus the upgrade cost at the start of the turn
  - Discover choices and selections during the Recruit phase (minions, Tavern spells, Triple Rewards, Trinkets, Hero Powers, etc.)
  - **Dark Gifts** Discover options, selections, and effects attached to minions
- **Board, Combat & Lobby Visualization**:
  - Your Hero Power at the end of each turn (including mid-game changes via spells, etc.), board state (positioning, stats, Golden status, keywords, Dark Gifts), and hand
  - Combat outcomes (Win / Loss / Tie, damage dealt/taken, life progression) along with the opponent's board and hero info
  - Full lobby leaderboard (you + 7 opponents) showing placement, hero, Tavern Tier progression, Health/Armor, Triple count, and Lesser/Greater Trinkets
  - Starting hero choices and automatic inference of active / banned minion types (tribes)
- **Japanese & English Report Output + Card Data & Art (`--lang ja` / `--lang en`)**:
  - Supports both Japanese (`ja`) and English (`en`) output for HTML reports and AI analysis Markdown.
  - Automatically fetches localized card names, texts, stats, tribes, Trinkets, Hero Powers, Dark Gifts, and card images from [HearthstoneJSON](https://hearthstonejson.com/) (`jaJP/cards.json` / `enUS/cards.json`). Falls back to CardIDs when offline or unavailable.
- **AI Analysis Markdown Output (`--ai-text` / `--ai-only`)**:
  - Outputs the same match information as the HTML report in a compact, tag-free Markdown format, complete with a **Card Glossary** containing only the cards that appeared in the match. Ideal for feeding into ChatGPT, Claude, Gemini, or other LLMs for gameplay review and coaching.

## Requirements

- **Python 3.x** (standard library only: `argparse`, `glob`, `gzip`, `html`, `json`, `os`, `re`, `sys`, `urllib.request`)
- **Internet connection** (optional: used to fetch card metadata and card images from HearthstoneJSON; works offline using CardIDs)

## Setup (`Power.log`)

To make Hearthstone output `Power.log`, enable `[Power]` logging in Hearthstone's `log.config` file.

The script searches for `Power.log` in the following order:

1. The `log_file` path specified as a command-line argument
2. The latest log in the default Windows installation path (`C:\Program Files (x86)\Hearthstone\Logs\Hearthstone_*\Power.log`)
3. `Power.log` in the current working directory

## Usage

```bash
python bg_review.py [log_file] [options]
```

### Options

| Option | Short | Description |
| --- | --- | --- |
| `log_file` | - | Path to the `Power.log` file to analyze (auto-detected if omitted) |
| `--output` | `-o` | Base output filename (default: `bg_review_rolls.html`) |
| `--split` | `-s` | Split output into separate files per game (applies to both HTML and AI Markdown) |
| `--game` | `-g` | Specify 1-based game numbers to output; accepts multiple values (e.g., `-g 1 3`) |
| `--ai-text` | `-a` | Also output lightweight Markdown (`*_ai.md`) for AI analysis alongside HTML |
| `--ai-only` | - | Output only the AI analysis Markdown without generating HTML |
| `--lang` | `-l` | Report output language for HTML and AI Markdown (`ja` / `en`, default: `ja`) |

### Examples

```bash
# Auto-detect the latest Power.log and generate bg_review_rolls.html (Japanese)
python bg_review.py

# Analyze a specific Power.log and generate both HTML and AI Markdown in English
python bg_review.py Power.log --ai-text --lang en

# Split output into one file per game (e.g., bg_review_rolls_game1.html)
python bg_review.py Power.log --split --lang en

# Extract and output only Game 1 and Game 3
python bg_review.py Power.log --game 1 3 --lang en

# Generate only AI analysis Markdown with a custom filename
python bg_review.py Power.log --ai-only --lang en -o review.md
```

## Output Files

- **HTML Report (default: `bg_review_rolls.html`)**
  - Open in a browser to visually review turn-by-turn rerolls, boards, combat results, and lobby standings.
  - With `--split`, files are named `<base>_game1.html`, `<base>_game2.html`, etc.
- **AI Analysis Markdown (`*_ai.md`)**
  - With `--ai-text`, files are named `<base>_ai.md` (or `<base>_game1_ai.md` with `--split`).
  - With `--ai-only` and `-o` ending in `.md` or `.txt`, the specified filename is used directly (or `<base>_game1.md` with `--split`).

---

## Notes

- This script depends on Hearthstone's internal `Power.log` format and the HearthstoneJSON API structure. Major game updates may change log formats and cause some fields to stop parsing accurately.
- `Power.log` may contain player names (such as BattleTags). Please be careful before sharing logs or generated reports publicly.
- Since the author only plays Battlegrounds Solo mode, logs mixing other game modes and Battlegrounds Duos mode have not been tested.
